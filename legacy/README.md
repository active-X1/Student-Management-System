# Legacy versions

The original learning versions of this project, kept exactly as they were written:

| File | What it is |
| --- | --- |
| `procedural.py` | First version: plain functions and a dictionary |
| `oop.py` | Second version: the same idea rebuilt with classes |

Both are single-file, terminal-only and store data in memory. **Campus Desk** (everything under `src/`)
is where they grew up: shared core, validation, SQLite storage and four interfaces.
