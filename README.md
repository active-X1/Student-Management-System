🎓 Student Management System

A Python-based Student Management System built progressively to demonstrate the evolution of my programming skills — from simple procedural code to structured Object-Oriented Programming and graphical applications.

This project was developed in four stages, with each version improving the structure, usability, and interface of the previous one.

---

🚀 Project Evolution

1. 🐍 Procedural Version

The project started as a simple Python program using procedural programming concepts.

Concepts used:

- Variables
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- Basic data management

This version focuses on understanding the fundamentals of Python and building the system using raw procedural code.

---

2. 🏗️ OOP Version

The system was then rebuilt using Object-Oriented Programming (OOP).

The goal was to make the code more organized, reusable, and easier to maintain.

Concepts used:

- Classes
- Objects
- Methods
- Encapsulation
- Constructors
- Object-oriented program structure

This stage represents the transition from procedural programming to more structured software design.

---

3. 🖥️ Tkinter Version

After building the system through the terminal, it was transformed into a desktop GUI application using Tkinter.

Instead of interacting with the program entirely through the terminal, users can interact with graphical elements such as:

- Input fields
- Buttons
- Student records
- Update functionality
- Delete functionality
- Search functionality
- Student management interface

This version introduced GUI development with Python.

---

4. 📱 Kivy Version

The final stage is the Kivy version, designed with mobile-friendly development in mind.

Kivy allows the project to move beyond traditional desktop interfaces and explore Python-based application development for mobile platforms.

This version focuses on:

- Touch-friendly interfaces
- Mobile application design
- Kivy widgets
- Event handling
- GUI-based student management
